# Drum Kit

An interactive web-based drum kit that lets you play drum sounds using your keyboard or by clicking the on-screen buttons.

## Features

- Play sounds by pressing the W, A, S, D, J, K, L keys on your keyboard
- Click the on-screen drum buttons to play sounds with the mouse
- Multiple drum sounds: crash, kick-bass, snare, and tom drums
- Built with vanilla HTML, CSS, and JavaScript

## How to Play

1. Open index.html in your browser.
2. Press a key from W A S D J K L or click a drum button to hear the corresponding sound.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (DOM manipulation and Audio API)

## Files

- index.html - main page structure
- styles.css - layout and styling
- index.js - sound playback and keyboard/click handling
- sounds/ - drum audio files
- images/ - drum button images

## Demo

No build step required - just open the HTML file or serve the folder with any static server:

npx serve
